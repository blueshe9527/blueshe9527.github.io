Python 薪資報表自動產生工具

這個練習使用 Python 讀取 employees.csv，計算員工薪資， 並將正常資料與錯誤資料分開輸出成報表。

  • 使用 csv.DictReader / DictWriter 處理 CSV 資料
  • 自動產生 salary_report.csv、error_report.csv
  • 使用 try / except 處理工時或時薪錯誤
  • 產生 summary_report.txt 統計正常、錯誤筆數與總薪資

學到的技能：CSV 處理、資料驗證、錯誤處理、檔案讀寫

Python 網站狀態監控與 LINE 通知工具

這個練習可以定期檢查網站是否正常連線，記錄狀態碼與回應時間， 並在網站異常或回應偏慢時發送 LINE 通知。

  • 讀取 config.json 設定網站清單
  • 使用 requests 檢查網站狀態
  • 自動寫入每日 log 紀錄
  • 使用環境變數保護 LINE Token
  • 支援 argparse 參數控制，例如 once、interval、timeout

學到的技能：網站監控、API 串接、Log 紀錄、環境變數、參數控制
